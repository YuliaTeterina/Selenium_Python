# Автоматизированное тестирование интернет-магазина с поддержкой разных языков интерфейса

## Описание проекта

Данный проект представляет собой набор автоматизированных UI-тестов для проверки работоспособности интернет-магазина с использованием Python, Pytest и Selenium WebDriver.

Основная цель проекта — обеспечить корректную работу интернет-магазина для пользователей из разных стран, независимо от выбранного языка интерфейса. Для этого реализована возможность запуска автоматизированных тестов с различными языковыми настройками браузера Google Chrome.

Проект позволяет передавать необходимый язык непосредственно через командную строку с помощью специального параметра `--language`. Это даёт возможность проверять отображение элементов сайта на разных языках без необходимости вручную изменять настройки браузера перед каждым запуском тестов.

## Основные возможности

- Запуск автоматизированных тестов с использованием Pytest.
- Управление браузером Google Chrome с помощью Selenium WebDriver.
- Поддержка различных языков интерфейса.
- Передача языка пользователя через параметр командной строки `--language`.
- Использование фикстуры `browser` для создания и закрытия экземпляра браузера.
- Автоматическая настройка языковых предпочтений браузера.
- Проверка наличия элементов пользовательского интерфейса на страницах интернет-магазина.
- Использование CSS-селекторов для поиска элементов страницы.

## Структура проекта

**conftest.py**

Содержит настройки Pytest и общие фикстуры проекта. В этом файле реализован обработчик параметра командной строки `--language`, который получает выбранный язык пользователя и передаёт его в настройки браузера Chrome.

Также здесь объявлена фикстура `browser`, отвечающая за запуск браузера с необходимыми языковыми параметрами и его корректное закрытие после выполнения теста.

**test_items.py**

Содержит автоматизированный тест, проверяющий наличие кнопки добавления товара в корзину на странице товара интернет-магазина.

Тест открывает страницу выбранного товара, находит кнопку добавления в корзину с помощью CSS-селектора и проверяет её отображение на странице.

## Используемые технологии

- **Python** — основной язык программирования проекта.
- **Pytest** — фреймворк для организации и запуска автоматизированных тестов.
- **Selenium WebDriver** — инструмент для автоматизации взаимодействия с браузером.
- **Google Chrome** — браузер, используемый для выполнения тестов.
- **Git и GitHub** — инструменты для управления версиями и хранения исходного кода.

## Запуск проекта

Для начала необходимо установить необходимые зависимости:

```bash
pip install pytest selenium
```

Для запуска теста с испанским языком интерфейса используется команда:

```bash
pytest --language=es test_items.py
```

Для проверки французского языка:

```bash
pytest --language=fr test_items.py
```

Также можно использовать другие поддерживаемые языковые коды, например `en`, `de`, `it` и другие.

## Цель проекта

Цель проекта — продемонстрировать практические навыки создания автоматизированных тестов, работы с Selenium WebDriver и Pytest, настройки браузера через параметры командной строки и организации тестовой инфраструктуры.

Реализованное решение позволяет упростить проверку локализации интернет-магазина, повысить надёжность тестирования и убедиться, что важные элементы пользовательского интерфейса корректно отображаются для пользователей с разными языковыми настройками.

Проект выполнен в рамках практического задания курса по автоматизации тестирования на Stepik.
